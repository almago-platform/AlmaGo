# AlmaGo — ancien hébergement Render (archivé)

Ce document conserve la trace de la configuration Render de l'ancien service `almago-dev`, suspendu le 08/10/2026.

**Render n'est plus le runtime de production canonique.** Le site public est hébergé sur le VPS Ubuntu. Voir [le runbook VPS](vps-runbook.md) pour le déploiement, la santé, les tests et la résolution des incidents.

Ne pas réactiver Render ou utiliser les anciennes URL `onrender.com` pour valider une release. L'ancien fichier `render.yaml` est conservé provisoirement comme référence historique ; ce n'est pas une instruction de déploiement actuelle.
