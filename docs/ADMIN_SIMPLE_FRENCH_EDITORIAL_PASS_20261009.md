# Campus Allemagne — français simple dans l'administration (9 octobre 2026)

## Portée de cette passe

Onze descriptions d'en-tête de l'espace administrateur ont été relues et simplifiées dans le code. L'objectif est de rendre les consignes quotidiennes plus rapides à comprendre sans changer les règles métier. Ce document n'atteste **pas** d'une relecture complète de toutes les étiquettes, erreurs, tableaux, formulaires, traductions ou messages utilisateur.

## Principes appliqués

- Commencer par un verbe concret : « Vérifiez », « Cherchez », « Suivez ».
- Garder une ou deux phrases courtes par écran.
- Dire « date » ou « date limite » plutôt qu'« échéance » quand le contexte ne nécessite pas le mot technique.
- Dire « informations vérifiées », « site officiel » et « dossier de l'étudiant ».
- Ne pas présenter une recommandation d'orientation comme une admission, ni une saisie administrative comme un visa accordé.
- Conserver les deux décisions distinctes pour un paiement : réception puis activation.
- Ne pas dire que Campus Allemagne classe les assureurs ou garantit des droits financiers.

## Périmètre exact des modifications

| Écran | Intention de la nouvelle description |
| --- | --- |
| Candidatures | Dossiers en cours, dates, informations visibles |
| Documents | Document actuel et versions précédentes |
| Validation du parcours | Proposition, accord, paiement, validation |
| Programmes | Recherche et vérification avant modification |
| Universités | Recherche et sources vérifiées |
| Cours de langue | Origine/date et distinction des types de cours |
| Finance et assurance | Informations officielles sans décision d'éligibilité |
| Paiements | Deux confirmations distinctes |
| Offres | Publication explicite |
| Équipe | Responsable, charge et suivi |
| Orientation | Recommandation distincte de l'admission |

## À tester en recette humaine

Faire relire les écrans avec des personnes qui travaillent réellement dans l'administration et qui n'utilisent pas les termes techniques du dépôt. Vérifier la compréhension des messages de blocage, du consentement commercial et des statuts de visa, notamment lorsqu'une source manque.

## Frontières

Aucune modification aux routes d'API, migrations, règles RLS, statuts, calculs de date ou contrôles d'admission. Les mentions juridiques des formulaires sensibles doivent être conservées. Les textes publics et les traductions AR/EN/DE ne sont pas inclus dans cette passe.
